Add it to
Add the server to your claude_desktop_config.json, then restart the app.
{
  "mcpServers": {
    "metra": {
      "command": "npx",
      "args": ["mcp-remote", "https://metra.remote-mcp.dev/mcp"]
    }
  }
}

Data source

Realtime GTFS feeds come straight from Metra's public API. Static schedule data is fetched from the published GTFS zip and cached; the realtime feeds are read on every tool call.
